# Contributing to Turncoat

Thanks for your interest in contributing.

## How to contribute

1. **Fork the repo** and clone your fork.
2. **Create a branch** for your change: `git checkout -b fix/your-change` or `feature/your-feature`.
3. **Install dev dependencies** (same as main app): `pip install -r requirements.txt`.
4. **Make your changes.** Prefer sentence casing and Material icons where it fits the UI.
5. **Test** by running `streamlit run streamlit_app.py` and exercising the affected flow.
6. **Commit** with a clear message (e.g. "Add X" / "Fix Y").
7. **Push** to your fork and open a **pull request** against the default branch.

## Code style

- Python: follow PEP 8; the project uses a simple structure (`app_pages/`, `lib/`).
- Prefer Streamlit’s native widgets and patterns; use Material icons over emojis in the UI where possible.

## Questions

Open an [issue](https://github.com/SiddhantSadangi/turncoat/issues) for bugs, feature ideas, or questions.
